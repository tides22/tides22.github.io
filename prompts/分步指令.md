# 给 Claude Code 的分步指令

用法：在 Claude Code 里打开“个人网站”这个文件夹，**按顺序一次复制一步**。每步做完先在浏览器里看效果，满意再进入下一步。不满意就直接用大白话告诉它哪里不喜欢，比如“绿色太刺眼了”“这里太挤了”。

---

## 第 1 步：规划（先不写代码）

```
请先阅读 CLAUDE.md，然后阅读 materials/ 文件夹里的所有内容。
这一步不要写代码。请用简单的话告诉我：
1. 网站的页面结构和导航
2. 首页从上到下放什么，为什么这样排能让面试官快速抓住重点
3. 2 个不同的视觉方向（都基于明媚的绿色和海蓝色），分别描述配色、字体、整体感觉，最好附上具体色值
4. 给我 3 个一句话定位的备选
5. 我的素材还缺什么，哪些【待补】最需要先补
```

## 第 2 步：做一个视觉小样

```
我选择视觉方向 [A/B]。
请先只做首页，用我的真实内容，让我看看整体感觉。
完成后告诉我怎么在浏览器里打开预览。
```

## 第 3 步：搭完整网站

```
首页的感觉我满意了。请按规划把 4 个板块都搭出来：
首页、项目（2 个深度案例页 + 3 个项目卡片）、经历、关于我。
materials 里还有【待补】的地方用醒目的占位符显示，不要编造内容。
完成后用 git 提交一次。
```

## 第 4 步：面试官视角检查

```
请假设你是一个互联网公司的产品经理面试官，第一次用手机打开我的网站：
1. 30 秒内你记住了什么？
2. 哪里看不出“我”具体做了什么？
3. 哪里信息太多或太少？
4. 哪里让你想继续了解这个人？
列出具体的修改建议，先不要改，等我确认。
```

## 第 5 步：加一点生命力（可选）

```
在“关于我”板块，请给我 2–3 个让它更有活人感、更好玩的小交互方案
（比如把爱好和项目连起来的设计、“最近在好奇的问题”卡片等），
说明每个方案的效果和工作量，我选了再做。
```

## 第 6 步：上线前检查

```
上线前请帮我检查：
1. 全站搜索有没有手机号或其他隐私信息
2. 所有图片是否已压缩、是否已清除 EXIF 定位信息
3. 用手机尺寸检查每个页面
4. 所有外部链接（Notion、Tableau、产品预览）能否打开
5. 网站有没有加载国内访问不了的外部资源（比如 Google Fonts）
6. 网页标题、分享时显示的标题和图片是否正确
```

## 第 7 步：部署

```
我的面试官主要在中国大陆，vercel.app 在国内打不开。
请比较几个能在国内稳定访问的免费或低成本部署方案（例如腾讯云 EdgeOne Pages），
说明各自的步骤、费用、是否需要买域名或备案，用新手能听懂的话给我推荐一个，然后一步步带我部署。
```

⚠️ 部署后，**请国内的朋友用手机流量和校园网各打开一次**，确认能正常访问（你现在在澳洲，自己测不准）。

## 记录过程（为以后加“AI 协作”板块做准备）
做的过程中，遇到这几种时刻截个图存到一个文件夹里：
- 你否决了 Claude 的某个方案，并说明了原因
- 你给出了一个改进想法，效果明显变好
- 同一个页面改版前后的对比
以后可以把这些做成一个“这个网站是怎么做出来的”页面，这是展示 AI 协作能力最有说服力的方式。
